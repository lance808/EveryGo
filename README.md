# EveryGo

Windows 便携式桌面启动面板：默认只有一个「＋」，添加 exe / bat / cmd 后单击图标启动。单 exe、免安装、免管理员、不联网、无第三方 DLL。

当前状态：**Phase 3 外观**（v0.3.0）。已具备纯色/图片背景、透明度、图片模糊、色调、玻璃开关、实时预览与恢复默认外观；添加/启动/移除、图标缓存、开机自启、托盘均已接入。

## 构建

环境：Windows 11 x64 + .NET Framework 4.8.1 + VS 2022 Build Tools（Roslyn `csc.exe`）。

```powershell
.\build.ps1            # 只构建，产物在 dist\EveryGo.exe
.\build.ps1 -SelfTest  # 构建并运行自检，打印自检报告
```

构建脚本自动定位 Roslyn `csc.exe`（优先 VS 2022 Build Tools），找不到时回退系统 `csc.exe`；都没有则明确报错。构建会重建 `dist\EveryGo.exe`，并把已有的 `dist\EveryGo.data` 临时移出后恢复，不会清掉应用列表与设置。

## 使用

```powershell
.\dist\EveryGo.exe
```

- **添加**：点击「＋」或右键面板空白处 →「添加应用」，选择 `.exe/.bat/.cmd`；重复路径会高亮已有图标并提示「已添加」。
- **启动**：单击图标启动。exe 使用 ShellExecute、工作目录为所在目录；bat/cmd 通过 `cmd.exe /c ""完整路径""`，工作目录为脚本所在目录。同一图标 400ms 内只响应一次。
- **脚本控制台**：默认最小化，可在设置中改为「显示 / 最小化 / 隐藏」。
- **右键图标**：启动 / 打开文件位置 / 移除（移除需二次确认）。
- **文件丢失**：图标变暗并显示警告点，悬停提示「文件不存在」，点击显示完整路径。
- **关闭按钮**：设置中可选「直接退出」或「最小化到托盘」；托盘模式双击恢复面板，右键菜单「显示面板 / 设置 / 退出」。
- **开机自启**：只写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\EveryGo`，值为带引号的当前 exe；exe 移动后下次启动自动修正。不管理其他应用自启项。
- **外观（设置窗口）**：
  - 纯色：颜色选择器 + 透明度 0–100%（默认 82%）。
  - 图片：选择 png/jpg/jpeg/bmp，自动复制到数据目录；可调图片不透明度、模糊 0–24px、色调强度 0–100%。
  - 玻璃质感开关（边框受光、阴影与内部磨砂）；「恢复默认外观」只重置外观，不清除应用列表。
  - 所有调整实时预览，400ms 防抖后原子写入；设置窗口自身保持固定深色玻璃，不跟随背景图。
  - 透明度低于 20% 时提示一次「可能影响可读性」。
- 窗口位置记忆、越界居中、置顶开关、单实例聚焦、网格 4/5/6 列可切换。

## 数据位置

优先 `exe 同目录\EveryGo.data\`（便携）；若不可写，自动回退到 `%APPDATA%\EveryGo\`，实际路径可在设置窗口查看。

```text
EveryGo.data\
  config.json
  config.bak.json
  EveryGo.log
  background\bg.png
  icons\<hash>.png
```

- 配置原子写入，保留上一版 `config.bak.json`；损坏时改名为 `config.corrupt-<时间>.json` 并以默认值启动提示。
- 图片导入后会转存为 `background\bg.png`，不依赖原图位置。
- 图标缓存按「路径 + 修改时间 + 大小」生成键，文件变化后自动刷新。

## 自检

```powershell
.\dist\EveryGo.exe --selftest
```

- 退出码 0 表示全部通过；报告写入 `%TEMP%\EveryGo.selftest.log`。
- 覆盖默认配置、保存/读取、中文与空格路径、损坏配置回退、外观钳制、`closeAction`、网格/控制台枚举、bat 引号与工作目录、重复路径、名称回退、原子备份、面板尺寸、启动参数、自启值判定、图标提取与缓存、深色控件样式解析。
- 自检不创建窗口、不写 Run 启动项、不修改真实配置（使用 `%TEMP%\EveryGo-selftest\` 临时目录）。

## 已知限制

- 主窗口使用 `AllowsTransparency` 分层透明窗口；系统 Acrylic 与分层窗口不兼容，因此玻璃质感由**内部磨砂 + 深色渐变 + 边缘受光**实现，按规格在真实模糊不可用时回退。
- 图片模糊使用 WPF 内部模糊，仅作用于背景图片，不影响控件文字。
- 不支持 URL、文件夹、`.lnk`、拖拽添加、自定义图标、分组/搜索/多页。
- 托盘只用于关闭到托盘与显示/设置/退出。
- 系统未开启 `LongPathsEnabled`，超过 260 字符的路径会给出明确提示而不是静默失败。
- 图标变化采用 10 秒轮询刷新，网络路径下可能有短暂延迟。
